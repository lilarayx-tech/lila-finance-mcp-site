Lila Finance MCP

A private, personal finance management application for one operator. It is not a public product, not a marketplace, and not a service offered to other people.

This application is still being set up. Gmail accounts are not connected yet. There is no public signup. Other people should not grant this application access to their Google data.

What this application is for

After the operator authorizes it on a Google Account, Lila Finance MCP is meant to:

  • Search and read Gmail in read-only mode to find receipts, purchases, refunds, and similar financial emails.
  • Extract structured fields such as date, amount, merchant, and identifiers so the operator can review them. Email text is treated as data to parse, not as instructions.
  • Show a preview of proposed journal entries before anything is written.
  • Insert new journal rows into a Google Sheet the operator already owns, only after the operator turns writes on. It does not replace that spreadsheet, and it does not change formula-driven tabs.

What this application does not do

  • It does not send, draft, forward, label, trash, or delete email.
  • It does not create public user accounts.
  • It does not sell data, serve ads, or train general-purpose AI models on Gmail or Sheets data.
  • It does not publish personal financial information on this website.

Google user data

How Gmail and Google Sheets data is accessed, used, stored, retained, and revoked is described in the privacy policy. That is the same policy that will be linked from the Google OAuth consent screen.

Lila Finance MCP’s use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
